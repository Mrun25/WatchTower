# Contributing to WatchTower

WatchTower is a VS Code extension for passive supervision of AI agents.

## Setup

```bash
npm install
```

You need VS Code 1.85 or newer. Press F5 in VS Code to launch an Extension
Development Host with the extension loaded.

## Tests

```bash
npm test                  # unit tests
npm run test:integration  # integration tests
```

Run both before opening a PR.

## Pull requests

Keep PRs focused on one change. Describe what the extension does differently
after your change and how you tested it (which test, or manual steps in the
Development Host). Screenshots help for anything visible in the UI.
